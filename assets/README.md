# assets/

Esta pasta está vazia de propósito. Toda a pixel art (`js/sprites.js`, `js/map.js`), os efeitos sonoros e a música (`js/audio.js`) são gerados por código na inicialização, então o jogo não depende de nenhum arquivo externo.

Subpastas reservadas para arte ou áudio feitos à mão no futuro:

- `sprites/`
- `sounds/`
- `music/`
